# Changelog

## 0.1.0

- Initial release.
- `.sdb` inspector (custom editor): header/magic check, stats, key sample,
  terminal actions (inspect, dump, serve).
- `.sdbc` command-script language: TextMate grammar + language configuration.
- Commands: init, inspect, start/stop/status, dump, run script.
- `superdb.json` schema validation.
- Status-bar key count.
